# Glossario Ufficiale - Neverness to Everness (NTE)
*Localizzazione Italiana a cura di Sici29*

Il presente glossario raccoglie i canoni terminologici applicati all'intera traduzione di Neverness to Everness (oltre 100.000 stringhe).

---

## 🏛️ Fazioni, Ruoli & Organizzazioni

| Termine Originale (EN) | Traduzione Ufficiale (IT) | Contesto & Note |
| :--- | :--- | :--- |
| **Appraiser** | **Valutatore** | Il titolo/ruolo del protagonista nell'agenzia Eibon. |
| **Anomaly Hunter** / **Hunter** | **Cacciatore di Anomalie** / **Cacciatore** | Chi affronta e neutralizza le anomalie urbane. |
| **Hunter Level** | **Livello Cacciatore** | Il grado di esperienza del cacciatore. |
| **Hunter EXP** | **ESP Cacciatore** | Punti esperienza per l'avanzamento di livello. |
| **Bureau of Anomaly** / **BAC** | **Ufficio Anomalie** | L'ente governativo di sicurezza e controllo delle anomalie. |
| **Anomaly Hunter Association** | **Associazione Cacciatori di Anomalie** | L'organizzazione di coordinamento dei cacciatori. |
| **Esper** | **Esper** | Individuo dotato di poteri soprannaturali. |
| **Esper Zero** | **Esper Zero** | Classe / Titolo proprio narrativo. |
